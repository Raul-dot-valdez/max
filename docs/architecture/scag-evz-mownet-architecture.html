Scag EVZ electrical and firmware architecture on the MowNet bus

Reconstruction of the Scag EVZ electric zero-turn network from published parts lists, Hydro-Gear Smartec material and trademark and certification records. Scag and Hydro-Gear have not published MowNet's message set, so the PGN list separates standard J1939 messages from proprietary traffic whose contents are unknown.

Controller units and their firmware

Each node's likely firmware responsibilities. Function lists are inferred from what each component class does on Smartec and similar 48 V electric mowers.

Bluetooth module 487051 CONFIRMED PART

  • Scag lists it as "Bluetooth, Smart Tec" in the EVZ electrical system
  • A device certification record lists Hydro-Gear 2810-1001 as a "MowNet bus to Bluetooth bridge". That it is the same unit is inferred
  • Firmware: CAN node + BLE GATT server, gateway between app requests and MowNet
  • Serves fleet and service data: hours, faults, SoC, configuration
  • Likely path for "on-demand upgradability" (OTA reflash of MowNet nodes)

Interface module 487054 CONFIRMED PART

  • Sold as "eVIM"; role on the bus is inferred
  • Reads key, PTO, E-stop and light switches, plus operator-presence inputs
  • Runs the machine state machine: off, ready, drive, mow, fault
  • Enforces interlocks (seat, park brake, PTO) before enabling drive and deck
  • Bridges analog controls onto MowNet, as Hydro-Gear describes

Battery + BMS CONFIRMED PACK

  • Vanguard 48 V 5 kWh lithium-ion
  • Vanguard packs have an integrated BMS and support J1939 (29-bit)
  • Firmware: cell monitoring, SoC/SoH, current limits, contactor control, charge control
  • Publishes SoC and limits that the display and controllers use (PowerSafe)

Traction controllers ×2 INFERRED

  • Drive the Hydro-Gear ZT-2800e brushless transaxles (confirmed)
  • Hydro-Gear designs the ZT-2800e to pair with the TC-2200 controller
  • Firmware: motor commutation/FOC, speed and torque loops, lap-bar position input
  • Regenerative braking, slope hold, thermal and current derating

Deck motor controller INFERRED

  • Drives Smartec D2e deck motors (confirmed on the EVZ)
  • Hydro-Gear lists the DC-2200 as "MowNet compatible (CAN)"
  • Firmware: blade speed control, soft start, blade-stop timing, load sensing
  • Load sensing feeds SmartMow, which adjusts power to cutting conditions
  • Number of controller channels for the 52 in deck is unconfirmed

Operator display INFERRED NODE

  • Scag confirms an operator information display: battery charge, run hours, diagnostics
  • That it is a MowNet node, rather than wired to the eVIM, is inferred
  • Firmware: CAN listener, fault-code display, hour meters

Fleet management data path through 487051

  1. Nodes broadcast status and DM1 faults on MowNet continuously while the key is on.
  2. The 487051 module listens on the bus and keeps the latest values. On request it asks nodes for on-request data such as identifiers and fault history.
  3. A phone connects over BLE. MyMow presents owner-level data: hours, charge, maintenance. Connect gives dealers diagnostics and adjustments. Install is the OEM's commissioning tool.
  4. The app forwards data to its cloud service. Fleet views therefore depend on someone opening the app near the machine, since the module has no cellular link of its own (inferred from the BLE-only description).
  5. Configuration changes and firmware updates travel the reverse path: app → BLE → 487051 → MowNet → target node.

Gaps worth noting for an AI Terra product: no on-machine GNSS, no cellular backhaul, and no on-device analytics are described for this system.
